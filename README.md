# Bless Us — 検証用モック
Phaser 3（固定 CDN 3.90.0）＋純粋 JavaScript ES modules。Nuxt・バックエンド・ビルドなし。ゲーム仕様の正本は Drive のゲーム仕様.md。ここは試作の起動・仮定の記録。

## 起動
GitHub Pages: Settings → Pages → Deploy from a branch → develop / (root) → Save。相対パスで動作する。公開用 Actions を使う場合は Source: GitHub Actions を指定する。main は受入前のため変更しない。
ローカル: `python -m http.server 8000` をリポジトリ直下で実行し http://localhost:8000/ を開く。Phaser CDN 接続が必要。
新規ゲーム→ラウンド開始→選択欄で能力を選ぶ→カードをクリック。AIで1操作または自動試遊も可能。全手札表示・ログJSON保存・初期デッキ変更はデバッグ用。

## 試作の仮定（確定仕様ではない）
- 同一端末の2〜6人、既定4人/3ラウンド、先手をラウンドごとに交代。HP上限なし、同点は同率勝者。通信・ルームサーバーなし。
- 発動元カード単位で効果を最後まで適用してから反応群を登録順に処理。複数トリガーが反応した個体は各トリガーごとに登録。通常処理はターンプレイヤー起点。ターン開始→ドロー→権利獲得→反応解決、終了時反応→権利0。脱落ターンは獲得判定のみ。
- 捨札イベントは移動前に反応登録、移動後に解決するため自身の捨札トリガーは再入手しない限り不発。初期配札ではドロートリガーを発生させず、通常ドローでは引いたカードも判定する。
- 発動履歴はラウンド単位で、発動時の効果を保存。初回の前回参照は不発。コピーは新個体（イベントのみ発動済み）。重複融合はトリガー集合和、数値効果は加算、非数値は1個。能力の5%重複は独立加算、追加発動は再抽選しない。
- 脱落はHP0の時点、連鎖終了後にラウンド終了。全滅は脱落順で得点。初期手札変更は配札後、各プレイヤーはターン順、能力は獲得順。追加カードの種類は50%ずつ。候補不足時は存在する候補だけを提示。ターン外の権利は当該プレイヤーに保持。
- 選択時は全生存者（自分含む）を提示。体力交換の差分は体力増減として扱う暫定実装。連鎖5000件超で検証用エラー停止。
