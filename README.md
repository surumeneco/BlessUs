# Bless Us — プロトタイプ

2〜6人のひとり対戦（CPU混在）と、LAN内通信対戦の試遊用実装。GitHub Pagesで配信し、PeerJS CloudによるシグナリングとWebRTCのホスト間直接通信を利用する。正式版ではない。

## 起動

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開く。GitHub Pages は `develop` のルートから配信。Phaser 3.90.0 が全画面・ゲームオブジェクト・座標・入力・モーダル・描画レイヤー・演出を管理する。HTML/CSS は起動・キャンバス面と文字入力時の一時的な標準入力欄に限定。描画バッファは端末画素密度（上限3）に合わせ、論理座標と表示サイズを一致させる。ブラウザ標準のダイアログは使用しない。文字入力欄以外のゲームUIはCanvasで管理する。

## 操作

- ホーム → ひとりで遊ぶ／みんなで遊ぶ：後者はルームを作成・参加し、名前と日本語・英数字の合言葉を入力する。ルームでは自分の手動／CPUを切り替え、ホストのみCPUスロットの追加・削除、ラウンド数、初期体力、脱落中のアビリティ獲得率、共通デッキを設定。乱数シードは未入力でランダム。手動プレイヤーの名前欄を押して変更。CPUはひらがな・カタカナから1文字ずつ無作為に選んだ3〜7文字の名前を自動生成し、開始時に行動4種・対象3種の方針を独立抽選する。
- パワー：設定 → パワーの設定でトリガー1つと効果1〜5単位（合計パワースコア0以下）を確定するか、未設定に戻す。プロフィールと同様にセッション中保持する。ルームでホストが有効にする（既定は無効）。公開パワーは対戦でプレイヤー枠の左に表示。CPU枠は持たず、切断によるCPU代行は本人の構成を維持する。
- 対戦：手札を上へドラッグして使用、横方向ドラッグで手札を移動。ホバーまたは長押しで詳細、選択後の使用ボタンでも使用可能。対象カード・プレイヤーを選択して決定。ターン枠とカード発動光は別の表示。発動済みトリガーは灰色表示。アクション権は宝石状の数字。
- カードの移動はエンジンが通知する個体・所有者・場所に基づき描画する。非公開手札はプレイヤー位置を起点・終点にし、公開されたカード以外の待機状態を漏らさない。発動元は発動履歴の連番による因果関係で特定し、直前のカードと異なる場合も独立表示する。実際のランダム／前回効果と処理行を表示する。ランダム効果の抽選候補切替演出は行わず、確定結果を標準速度で650ms表示してから解決・対象選択する。
- ラウンド開始のアビリティ選択とラウンド終了の改変は全員並行。各端末は自分の選択だけを操作する。生存点・能力点の加算、順位・座席更新。
- 最終ラウンドは改変なし。手動プレイヤーがベストカードに投票し、変更回数最多の全員に得票点を加算。結果からルームへ戻る。
- 初期デッキはプリセット「ベーシック」（50枚）または保存済みデッキから選択。プリセットを元に新規カスタムデッキを作成できる。
- デッキカスタマイズ：40〜60枚、各イベント1枚以上、最大100デッキの名前付き保存・複製・編集・マトリクス。保存先は端末内 localStorage。デッキ名・プレイヤー名・合言葉・乱数シードはブラウザ標準の一時的な入力欄を使用し、端末標準のキーボード、IME、貼り付けに対応する。ゲーム内仮想キーボードは設けない。
- 設定：「見た目の変更」で色・目・口・アクセサリを個別選択。初期外見はランダム。名前・外見はページを開いている間だけ保持する。音量（初期50%）・演出速度・演出軽減・手札重ね表示。ログは最新の項目を最初に表示し、公開済みの発動だけを展開する。ログ番号と実際の発動元を対応付け、分岐線で因果関係を示す。

通信対戦はホストがゲームを進行する。ゲスト切断中はCPU代行となり、同じ名前・合言葉で参加すると最新状態へ復帰する。ホスト切断時は対戦終了。名前は本人認証ではない。STUN（stun:stun.l.google.com:19302）を使用して直接通信の候補を追加し、TURNによる中継は行わない。配信・シグナリング・STUNにはインターネット接続が必要。同一LANでも接続できない環境があり、LAN外もネットワーク条件によって直接接続可能。接続に失敗した場合はDevToolsのConsoleで `[Bless Us network]` の診断ログ（シグナリング、ICE候補の種類・状態、DataChannel、参加要求・応答）を確認する。合言葉・名前・IPアドレス・SDPは診断ログに出力しない。

## 検証

```sh
node test.mjs # パワー専用テストも実行
node prototype-test.mjs
node feedback-test.mjs
node native-test.mjs
node polish-test.mjs
node balance-test.mjs
node profile-test.mjs
node turn-resolution-test.mjs
node lan-test.mjs
npm install --no-save --no-package-lock playwright@1.56.1 phaser@3.90.0 peerjs@1.5.5 peer@1.0.2
npx playwright install chromium
# 静的サーバー起動後
node browser-test.mjs
```

ブラウザ検証は実際のPhaserのCanvasを起動し、画面サイズ・画素密度・ポインタ座標・タッチ長押し・手札ドラッグ・並行選択・他プレイヤーの発動位置を確認する。検証用のスナップショット・カード描画フィクスチャは `?test=1` の場合のみ利用可能。実機・色覚・演出の体験品質は別途確認する。
