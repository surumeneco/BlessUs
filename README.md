# Bless Us — プロトタイプ

2〜6人の同一端末対戦（手動／CPU混在）。ゲームルール検討用エンジンを使用する試遊用実装。通信対戦・正式リリースではない。

## 起動

```sh
python -m http.server 8000
```

`http://localhost:8000/` を開く。GitHub Pages は `develop` のルートから配信。Phaser 3.90.0 が全画面・ゲームオブジェクト・座標・入力・モーダル・描画レイヤー・演出を管理する。HTML/CSS は起動とキャンバス面のみ。描画バッファは端末画素密度（上限3）に合わせ、論理座標と表示サイズを一致させる。ブラウザ標準のダイアログ・ゲーム内DOM操作要素を使用しない。

## 操作

- ホーム → ルーム：手動／CPUを切り替え、人数、ラウンド数、初期体力、脱落中のアビリティ獲得率、共通デッキを設定。乱数シードは未入力でランダム。
- 対戦：手札を上へドラッグして使用、横方向ドラッグで手札を移動。ホバーまたは長押しで詳細、選択後の使用ボタンでも使用可能。対象カード・プレイヤーを選択して決定。ターン枠とカード発動光は別の表示。発動済みトリガーは灰色表示。アクション権は宝石状の数字。
- カードの移動はエンジンが通知する個体・所有者・場所に基づき描画する。非公開手札はプレイヤー位置を起点・終点にし、公開されたカード以外の待機状態を漏らさない。実際のランダム／前回効果と処理行を表示する。
- ラウンド開始のアビリティ選択とラウンド終了の改変は全員並行。同一端末の手動プレイヤーは未確定の選択を切り替えられる。生存点・能力点の加算、順位・座席更新。
- 最終ラウンドは改変なし。手動プレイヤーがベストカードに投票し、変更回数最多の全員に得票点を加算。結果からルームへ戻る。
- デッキカスタマイズ：40〜60枚、各イベント1枚以上、最大100デッキの名前付き保存・複製・編集・マトリクス。保存先は端末内 localStorage。デッキ名と乱数シードの入力はゲーム内キーボード（英数字・ひらがな・濁音等）とPCの直接キー入力に対応。OSの漢字変換IMEは未対応。
- 設定：音量（初期50%）・演出速度・演出軽減・手札重ね表示。ログは最新の項目を最初に表示し、公開済みの発動だけを展開する。

## 検証

```sh
node test.mjs
node prototype-test.mjs
node feedback-test.mjs
node native-test.mjs
npm install --no-save --no-package-lock playwright@1.56.1 phaser@3.90.0
npx playwright install chromium
# 静的サーバー起動後
node browser-test.mjs
```

ブラウザ検証は実際のPhaserのCanvasを起動し、画面サイズ・画素密度・ポインタ座標・タッチ長押し・手札ドラッグ・並行選択・他プレイヤーの発動位置を確認する。検証用の読み取り専用スナップショットは `?test=1` の場合のみ利用可能。実機・色覚・演出の体験品質は別途確認する。
