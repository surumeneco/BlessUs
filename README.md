# Bless Us — プロトタイプ

2〜6人の同一端末対戦（手動／CPU混在）。ゲームルール検討用モックの `engine.mjs` を拡張し、確定UIデザインを反映した試遊用実装。本開発・通信対戦・正式リリースではない。

## 起動

```sh
python -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開く。GitHub Pages は `develop` のルートから配信できる構成。バンドル・ビルド不要。Phaser 3.90.0 はゲームオブジェクトと演出の描画を担当する。HTMLの入力・操作要素と描画レイヤーを分離し、カード、円卓、座席、山札、発動カードの移動はPhaserの描画オブジェクトで表現する。Phaserを取得できない場合は対戦開始時にゲーム内エラーを表示する。

## 操作

- ホーム → ルーム：手動／CPUを切り替え、人数、ラウンド数、HP、脱落時のアビリティ獲得率、共通デッキを設定。seed は空欄でランダム。
- 対戦：手札を上へドラッグして使用（使用時トリガーがある場合に発動）。横方向ドラッグで移動、ホバーまたは長押しで詳細、選択後の使用ボタンでも発動。対象カード・プレイヤーを選択し決定。ターン枠とカード発動光は別の表示。アクション権は宝石状の数字。
- ラウンド開始のアビリティ選択とラウンド終了の改変は全員並行で処理し、同一端末の手動プレイヤーは未確定の選択を切り替えられる。ラウンド終了：得点加算、順位更新、改変選択と確認。次ラウンドでは低得点順に席を並べ直す。同点は直前の席順を維持。
- 最終ラウンドは改変なし。手動プレイヤーがベストカードに投票、変更回数最多の全員に得票点を加算。新規生成・追加は変更履歴0回。コピー・融合は履歴継承。合計得点が同点なら最終ラウンド生存順位で決着。結果からルームへ戻る。
- デッキカスタマイズ：40〜60枚、各イベント1枚以上、最大100デッキの名前付き保存・複製・編集・マトリクス。保存先は端末内 localStorage（試作上の選択）。
- 設定：音量・演出速度・発光軽減・手札重ね表示など。対戦中のログは公開情報のみ、全対戦検証ログは終了後に保存可能。

## 検証

```sh
node test.mjs
node prototype-test.mjs
node feedback-test.mjs
node --check app.mjs
node --check engine.mjs
node --check presentation.mjs
```

旧ルール回帰テスト45項目（最終ラウンド改変省略と確認操作に合わせて期待値を更新）、新ルール10項目。ブラウザ試遊・実機タッチ操作・演出速度および配色の実地評価は別途必要。既存の試作上の未確定境界は設計課題を参照。
